## Optimization explanation

### 1. Spice Route Biryani (local restaurant) — Home page

**Target keyword:** `biryani restaurant in Bengaluru` · **Secondary:** best biryani near me, Hyderabadi biryani Bengaluru, biryani home delivery

Local searches include the city, so the keyword pairs the dish with 'Bengaluru'. The brand comes first because a restaurant's name is what returning customers search for. The meta gives the area (Koramangala) as a local signal, names the specific style (dum biryani) to set it apart, lists the three ways to order and ends with two calls to action.

### 2. GadgetKart (e-commerce store) — Product page

**Target keyword:** `boAt Airdopes 141` · **Secondary:** boAt Airdopes 141 price, wireless earbuds under 1500, TWS earbuds

Shoppers search the exact model name, so it opens the title, followed by the product type. 'Price & Offers' matches what buyers add to their search when they are ready to purchase. The meta leads with 'Buy' and the three specs people compare most, then answers their next questions (price, offers, delivery). Specs are taken from the product listing so the description stays accurate.

### 3. CodeWithNischay (tech blog) — Blog post

**Target keyword:** `learn Python for beginners` · **Secondary:** Python roadmap, Python basics, how to start coding in Python

The title is the phrase beginners type into Google, with a promise ('step-by-step roadmap') that tells them the format of the article. The meta speaks directly to the reader ('New to coding?'), repeats the keyword once, previews the four sections of the post and ends with an achievable outcome that encourages the click.

### 4. SmileCare Dental Clinic (local service) — Service page

**Target keyword:** `teeth whitening in Pune` · **Secondary:** teeth whitening cost, professional teeth whitening, dentist Pune

Service plus city is the standard local search pattern, and it opens the title. The clinic name comes after the separator to build trust. The meta stresses safety and qualified dentists, which matters for medical services, answers the cost question people have without promising a price, and ends with an easy next step. It avoids results claims like 'guaranteed white teeth', which would be misleading.

### 5. Nischay Prasad (developer portfolio) — Home page

**Target keyword:** `full stack developer portfolio` · **Secondary:** React Node.js developer, full stack engineer India, hire full stack developer

Recruiters search a person's name or their role, so the title has both: name first for navigational searches, role and 'portfolio' for discovery. The meta states the stack recruiters filter by, points to a real project as proof of work, and closes with a clear contact call to action.

## Principles applied

- Titles 47–53 characters, metas 154–159 characters (no truncation in results)
- Keyword leads the title, or follows the brand when the brand itself is searched
- Every title and keyword unique
- Wording matched to intent: local (city name), transactional (price/offers), informational (the reader's question), navigational (name first)
- Clear value + call to action in each description
- No misleading claims (no “best”/“#1”, specs from the listing, no guaranteed medical results)
