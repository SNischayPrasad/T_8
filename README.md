## Optimization explanation

### 1. Home — `scam message checker`

Primary keyword sits at the very start of the title, where Google and users weigh it most. 'SMS & WhatsApp' names the two channels people actually search for. Brand goes last so it never pushes the keyword out of view. The meta repeats the keyword idea, lists the three message types the app handles, states two differentiators (no uploads, no sign-up) and ends with a clear call to action.

### 2. How It Works — `on-device scam detection`

Leads with the exact keyword and uses a colon to separate the topic from the promise of the page. This is the only page targeting 'on-device', so it does not compete with the Home page. The meta answers the biggest worry users have (privacy) and tells them what they will find on the page (a step-by-step explanation), which matches search intent for a 'how it works' query.

### 3. Download — `scam detection app for Android`

Starts with the action verb 'Download', matching transactional intent: people searching this want to install something. The keyword follows immediately and includes the platform so iPhone users are not misled. The meta lists concrete features (three input types, background scanning) and closes with a direct call to action.

### 4. UPI Fraud Guide — `how to identify UPI fraud`

Uses the question exactly as people type it into Google, which matches informational intent and is likely to earn clicks from People Also Ask style results. The brand is left out of the title to keep it under 60 characters and keep the focus on the reader's problem. The meta opens with three specific scam types the reader will recognise, then promises both detection and next steps.

### 5. WhatsApp Scam Guide — `WhatsApp scam messages`

Keyword at the front, followed by a two-part benefit (what the tricks are and how to spot them). It targets a different platform and keyword from the UPI guide, so the two guides do not cannibalise each other. The meta uses familiar examples that Indian users receive daily, adds a location signal ('in India') and ends with a practical reason to read now.

## Principles applied

- Titles 46–56 characters, metas 152–158 characters (no truncation in results)
- Target keyword at the start of every title
- Every title and keyword unique — no keyword cannibalisation
- Wording matched to search intent (commercial / informational / transactional)
- Clear value + call to action in each description
- No misleading claims (no “free”, “best”, “#1”; platform stated)
